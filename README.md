# 张子健个人网站 Demo

AI 产品经理个人作品集 Demo，重点展示 Agent 平台、AI 基础设施、业务结果与 Vibe Coding 能力。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 内容维护

- `src/content.ts`：关键数据、项目与经历
- `src/App.tsx`：页面结构与交互内容
- `CONTENT_TODO.md`：后续内容采集模板
- `public/portrait.png`：当前个人肖像

当前 Vibe Coding Lab 是本地静态交互，尚未连接真实大模型。
